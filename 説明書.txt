FamiDriverCLI 説明書

■記述方法

Music番号 {} の中に Trackを定義していきます。

例:
Music0 {
	Track0,0 t120 cdefg
	Track1,1 efgab
	Track2,2 ...
}

いちばん数値の小さいMusicから再生されます。
Trackの引数はトラック番号,音源番号です。
音源番号は0と1が矩形波、2が三角波3がノイズ4がDPCM。
（拡張音源は下記の対応表参照）
トラックは0～15まで使えて、同じ音源番号のトラックは
数値の小さい方が優先して再生されます。

N163を使用する場合は、Music {} 内の最初のTrackより前に
N163CH 1～8で発音数を指定できます。省略時は8です。
発音数は曲の再生中には変更できません。

例:
Music0 {
	N163CH 4
	Track0,14 ...
	Track1,15 ...
}

N163波形は全曲で共有されます。波形データの合計サンプル数は
256 - 16 x（全Music中で最大のN163CH）まで使用できます。
各波形の長さは4以上の4の倍数で、上記の合計サンプル数以下です。


エンベロープは@E番号{}で定義します。

例: @E0 { 3 2 F10 | 1 | 0 }

数値は10進、$16進、%2進が使えます。数値の後にF数値で待ちフレーム指定です。
省略すると1フレーム待ちになるので同じ数値を並べて書いても同じですが
並べた数だけデータが増えますので無駄になります。
1個目の|がループで戻る先の場所で、2個目の|がリリース後のエンベロープになります。
どちらも省略可能です。|が1個になるとリリースが無効になり
0個になると戻り先が先頭になります。
エンベロープ指定は@v0,10のようにすると後ろの数値がディレイ指定になります（省略可）。
エンベロープは違う種類間で使い回しできます。

音程エンベロープとデチューンの値はレジスタ値に直接加算されます
ノートエンベロープやソフトウェアスイープの開始終了値は半音単位でノートナンバーに加算されます
（スイープの増加値はレジスタ加算）


@M番号でコマンドを音階に割り当てるノートマップが指定できます。

例:
@M0 {
	c4    @v0 @f0
	d4 e4 @v1 @f*
}

割り当てノートナンバーと変換先のノートナンバーのあとにコマンドを書きます。
使いたいトラック中に@M番号を記述すると変換されます。@M*で解除です。


@dpcmでDPCM定義できます。番号・初期値・ループフラグ（0: 無効、1: 有効）・ファイルパスをスペース区切りで記述してください。

例:
@DPCM {
	0 0 0 "kick.dmc"
}

ファイルパスは絶対パス・MMLファイルからの相対パスどちらでも大丈夫です。
@コマンドで割り当てた番号を指定するとファイルが切り替わります。
再生周波数は音階と対応しています（o0cで最大o1d+で最低）
音階に音色を割り当てたい場合はノートマップを使用し
@コマンドを指定してください。

※ノートマップでDPCMを使用しているときにキーシフトを使用しても
音程が変わるだけで音色が変わらないので正常に再生されません。


拡張音源を使う場合、使いたい音源を#ExpDeviceで指定して
後述の対応表の音源番号をトラック番号の後で指定すれば使えます。
FDS音源の場合@fdswで音色を、@fdsmでモジュレータを定義したのち
トラックで@音色番号、@fdsmモジュレータ番号を指定してください。（モジュレータは省略可）


■コマンド一覧
コマンドはLとKとQ以外は大文字小文字の区別はありません。

・トラック外に書くコマンド

#Title		タイトル
#Artist		アーティスト
#Copyright	著作者
#Timebase	4分音符x4当たりのティック数
			テンポ未指定の場合、1フレームが1ティックになるので
			ここで指定した数値により曲の速さが増減します
			デフォルトは96なので24フレームで1拍になり、60フレーム（1秒）で2.5拍
			60秒で150拍つまり150bpmになります。
			
#OffsetPCM	DPCMデータをオフセットして場所をあけるコマンド
#OffsetV	音量エンベロープの値を呼び出すときにオフセットします
#OffsetF	音程					〃
#OffsetN	ノート					〃
#OffsetT	音色					〃
#ExpDevice	拡張音源の指定。MMC5 SS5B VRC6 VRC7 FDS N163が指定できます。
			複数指定すると全音源対応のバイナリになります

@M番号 { }		ノートマップ定義
@DPCM { }		DPCM定義
@FSDW番号 { }	FDS波形定義
@FDSM番号 { }	FDSモジュレータ定義
@N163W番号 { }	N163波形定義
@VRC7U番号 { }	VRC7ユーザー音色定義。番号は0～255、$00～$07レジスタの値を10進数、$16進数、%2進数で指定

\番号 { }		サブルーチン定義（番号は0～255まで）
				ここに記述したMMLはドライバにそのまま埋め込まれ、トラック内から\番号で
				呼び出すことができます。

$文字列 { }		マクロ定義（文字列は英数のみ）
				ここに記述したMMLはトラック内で指定するとコンパイル時に展開されます。


・トラック内に書くコマンド

cdefgab	音符。%をつけるとフレーム音長。~で装飾符。
		装飾符は後ろに指定した数値分のフレームを鳴らして次の音符からそのフレーム数を引きます。
		（例：c~4d4 はcを4フレーム鳴らして4分音符から4フレーム引いた長さでdを鳴らす）
r		休符
r-		エンベロープ無効
<>		相対オクターブ
o		絶対オクターブ
[		ループ開始
]		ループ終了
:		ループ途中終了
q		ゲートタイム（音長-n。他と排他）
u		ゲートタイム（音長n。他と排他）
Q		ゲートタイム（音長n/8。他と排他）
k		キーシフト相対指定
K		キーシフト絶対指定
^		タイ
&		スラー
@		音色指定（FDSとN163の波形、VRC7のプリセット音色もこれで指定する）
		SS5Bでは@矩形波1,矩形波2,矩形波3の順に3値を指定する（0: トーン、1: ノイズ、2: トーン＋ノイズ）
		ノートマップ内でSS5B音色を指定する場合も同じ3値形式を使用する
t		テンポチェンジ（トラック中に記述すること）
@p		指定した曲番号のデータを再生
@v		音量エンベロープ指定（番号の後にカンマ＋数値でディレイ指定）
@v*		音量エンベロープ停止
@f		音程エンベロープ指定（番号の後にカンマ＋数値でディレイ指定）
@f*		音程エンベロープ停止
@n		ノートエンベロープ指定（番号の後にカンマ＋数値でディレイ指定）
@n*		ノートエンベロープ停止
@t		音色エンベロープ指定（番号の後にカンマ＋数値でディレイ指定）
@t*		音色エンベロープ停止
L		無限ループ
l		デフォルト音長
v		トラックボリューム絶対指定（0～15）
v+-		トラックボリューム相対指定（-15～+15）
@d		デチューン
hs		ハードウェアスイープ（引数は変化速度, 変化方向, 変化量）
		（変化速度0～7 0=早い 7=遅い, 変化方向0～1 0=下降 1=上昇, 変化量0～7 0=多い 7=少ない）

he		ハードウェアエンベロープ（引数は 変化速度, ループするしない）
		（変化速度0～15 0=早い 15=遅い, ループ0～1 0=ループしない 1=ループする）

s		ソフトウェアスイープ（引数は 開始音程, 終了音程, ディレイ, 変化度合)
		（音程差-64～63、変化度合-7～-1または1～7）
		（正の変化度合1～7はシフト回数3～9、負の変化度合は1を加算するフレーム間隔）

s*		ソフトウェアスイープ無効
\		定義したサブルーチンの呼び出し
$		定義したマクロを展開
pd		疑似ディレイ（引数は ディレイ, ボリューム, 何分音符短くするか）
w		メモリ書き込み（書き込みアドレス, 書き込むデータ。16進指定。）
@M		ノートマップ番号指定
@FDSM	FDSモジュレータ番号指定
@FDSE	FDSモジュレーションエンベロープ指定
@FDSG	FDSモジュレーションゲイン指定
@FDSF	FDSモジュレーション周波数指定。マイナスの値を指定するとキャリアと同期
@FS		ピッチエンベロープの値を引数に指定した数値だけ左シフトする（0～7）
@VRC7U	定義したVRC7ユーザー音色を選択（VRC7トラック専用）
